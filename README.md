This repository was created for the SWE 442 homework assignment about Software Configuration Management.

The purpose of this repository is to demonstrate basic version control and change management practices using GitHub. It includes repository setup, branching, feature development, pull requests, issue tracking, and documentation updates.

This is aa SCM Best Practices

Some important SCM best practices include writing clear commit messages and using branches for new changes and reviewing updates through pull requests and keeping the main branch stable. 
It is also important to track issues properly so that changes are documented and easy to understand later.
